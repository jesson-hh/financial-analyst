# Changelog

## 0.1.0 — 2026-09-16

This is the first consolidated Guanlan V2 release. It combines the previously
separate product-integration, research-workflow, memory, and Telegram channel
lines with the source currently validated by the local workstation.

### Included

- durable agent conversations, interruption/steering, archives, workspace
  memory governance, proactive recall, and research artifacts;
- data screening, factor specifications, temporal integrity checks,
  orthogonalization, overfit audits, model training gates, and workflow
  authoring/recovery;
- historical daily screening and simulated rebalancing with immutable
  artifacts and fail-closed price-quality checks;
- realtime watch evidence, research-space projection, company-research and
  evidence/PIT controls;
- controlled chart, image, and document publication;
- session-scoped Telegram outbound delivery, pairing, confirmation, durable
  outbox, media policy, and automation lifecycle;
- updated UI, documentation, configuration templates, and sealed tests.

### Deliberately excluded

- API keys, Telegram tokens, HMAC keys, private conversations, and local
  research-space state;
- market databases, generated reports, model weights, factor-mining output,
  screenshots, logs, backups, and workflow run artifacts;
- broker execution and automatic live trading.

### Research-data boundary

Historical strategy comparison remains fail-closed when the source lacks a
complete, verified adjustment history or contains invalid OHLC rows. Such runs
are diagnostics only and must not be presented as validated performance.
