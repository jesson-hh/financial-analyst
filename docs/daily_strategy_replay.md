# 历史筛选与日频模拟调仓

用于手操选股和规则验证，不连接券商、不下单、不发布模型。

## 工作流接法

`source.data → history_screen.src → history_screen.history → daily_backtest.history`

- 数据源：显式具名指数或指定代码、日线、起止日期。当前最多1200只、200万个日期×股票单元。
- 历史逐日筛选：`branches` 是1至8个既有受控筛选请求。分支内部条件AND，分支之间OR并去重。预热从source.start开始，`evaluation_start`独立控制账本起点。
- 当前固定排序：`nearest_ma10_ma20`，负的最近MA10/MA20绝对乖离；越接近均线越优先，并列按股票代码排序。不是收益预测概率。
- 日频模拟调仓：日频、TopN固定槽位。Top10但仅3个候选时，每只目标约10%，其余现金。每个交易日重新计算目标，不等于每天机械卖光重买。

`data_screen.candidates` 仍是当前截面结果，不能连接历史回放。原有因子`backtest`节点语义保持不变。

## 模拟时间与缺失数据

收盘形成信号，下一交易日开盘模拟成交。首日现金，不使用评估前信号提前建仓。只尝试已选股票，不能因未来退出价格缺失而改选其他股票。

缺开盘价的买入留现金，卖出受阻的持仓保留。缺收盘价的持仓按最近已观测收盘价（必要时入场开盘价）估值并标注陈旧，报告披露次数及末日未解决持仓。这是研究估值假设，不是制造可成交报价。

固定交易日历保留空仓日；数据覆盖不足的日期跳过下一次调仓，不能当作真实空池而全部卖出。最后一天只估值，不虚构区间外卖出。

手续费、卖出税率、滑点由节点显式配置。当前用分数股和统一比例成本；不含最小手续费、整手限制、独立公司行动现金流、真实市场冲击或完整历史涨跌停/停牌成交约束。

## 证据与持久化

历史价格门禁先核验完整源交易日历、OHLC同日约束以及与价格内容绑定的因果复权凭证。发现矛盾、非正/无穷价格或缺少可信复权来源时，历史筛选和日频回放均停止；证书只接受服务端行情适配器来源，策略参数与对话不能绕过。缺行/NaN仍按显式缺价规则处理，大幅波动只告警，不按未来表现删股删日。

旧历史产物即便哈希完整，也会重新经过价格门禁。旧的未认证结果保留为诊断证据，界面隐藏收益图、绩效指标和报告导出，不冒充有效策略业绩。哈希证明内容未变，不证明行情正确。

历史行情、信号、交易日历和规则存为独立不可变产物，引用带完整SHA256。读回必须核验文件内容及研究空间归属；修改源行情不会改写旧运行。工作流仍由现有服务端持久化运行机制承载，页面切换不取消任务。

结果包含逐日候选、选择、现金、持仓、未成交原因、模拟成交、净值、费用及平仓回合。账户正收益日占比与平仓回合胜率分别展示，不冒充选股成功率。

HTTP节点接口：

- `POST /workflow/history-screen`：`{params, context, workspace_id}`。
- `POST /backtest/daily-screen`：`{history, params, workspace_id}`，`history`必须是已验证历史产物引用。

优先用`/workflow/run/start`执行完整图并通过运行记录重连。

## 比较策略时的边界

本轮六组规则在执行前固定，统一股票池、日期、TopN和成本。比较开发描述段、预定验证段与近期描述段，以及零成本/双倍成本敏感性。不以同一结果反复调参后宣称最优。

当前中证800是静态成分，ST主表是当前快照，存在成分与幸存者偏差；2026区间已经受旧研究触及，不是全新盲测。结果能支持有限条件下的研究比较，不是对未来收益的证明。

2026-09-12实机验收：六组规则运行及账本数学核对完成，但710,785行共享源面板有993行OHLC约束矛盾，且复权因子更新不完整。因此本轮状态为`diagnostics_only`，不发布策略收益排名。参见[历史价格缺口调查](history_price_data_gap_20260912.md)。必须补齐独立、经过验证的研究行情快照后，原规则全六组重跑；不回写或猜测修复全局原始数据。

时间约定参考[Backtrader订单执行说明](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/)；按时间先后分段的评估原则参考[scikit-learn时间序列验证说明](https://sklearn.org/stable/modules/cross_validation.html)。实现是观澜独立账本，不声称复刻这些工具全部成交机制。
