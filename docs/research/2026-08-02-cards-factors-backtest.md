## 没有证明什么

- 单一模型(deepseek-chat fast)、56 交易日、3 只票、单一时钟参数;换 reasoner 深度模式或更长窗口结论可能不同。
- 交易笔数普遍是个位数,收益差异的统计显著性**没有**建立——所有收益对比只应作为方向性证据。
- 第二轮扫描是 in-sample 择优,只有留一外推那两列可外推。
- 新卡是随 A3 整体上的,单卡贡献未做消融。

## 建议的下一步(按性价比排序)

## 第五轮:结构改造治卖出 —— 实施 + 判决(用户点名)

按第四轮结论「持有偏好是结构问题」做了改造(`guanlan_v2/seats/api.py`):

1. **修真 bug**:持仓段旧文案让模型填 `side` / `note`,而 schema 要的是 `direction` / `rationale`
   ——字段名对不上,模型被要求填两个不存在的字段。
2. **必答字段**:持仓语境下 `position_action` ∈ {继续持有, 减仓, 清仓} 升为必填;
   它是这一问的答案,故由它决定 `direction`(清仓/减仓→卖出 + `exit_fraction` 1.0/0.5;继续持有→观望)。
   缺失或非法取值 → 一律不落地、不猜方向,诚实降级为模型原 `direction`。
3. **空仓路径逐字节不变**(红线):不带 `hold_entry` 时 prompt / 响应 / 落盘形状与改造前完全一致。

测试:新增 `tests/test_seats_decide_exit_action.py` 9 项(全绿);一处旧钉有意识翻面
(`test_seats_decide_hold.py::test_hold_injects_block` 原本钉的是被修掉的错误文案,意图不变、形态更新);
decide 邻域回归 551 绿。

**同臂同窗口同票对照(唯一变量=本次改造):**

| 指标 | 第四轮(改造前) | 第五轮(改造后) |
|---|---|---|
| 持仓提问 | 41 | 42 |
| 了结卖出 | 2 | 2 |
| **卖出率** | **4.9%** | **4.8%** |
| 必答字段填充率 | —(无此字段) | **42/42 = 100%** |
| 减仓(旧 schema 无法表达) | 0 | 1 |
| 三票等权收益 | +2.6% | +5.7% |

**判决:改造没有提高卖出率。** 我押的「改结构就能治」被自己的实验证伪了一半。

换来的是另外三样东西:①**可审计**——出场评估从此一定发生过且留痕(100% 填充);
②**新表达力**——两次了结里有一次是「减仓」,旧 schema 只有全进全出,这个动作以前根本表达不出来;
③修掉了字段名错配的真 bug。

收益从 +2.6% 到 +5.7%,但**只有 2 次卖出,这是噪声不是证据**,不拿来当改造有效的依据。

**修正后的结论(已回写 EV-033,并新立 EV-035)**:行为缺口分三层——
知识缺口(加卡有效,3%→13% 扣扳机)、接口缺口(改 schema 有效,但只换表达力与可审计)、
**判断倾向**(前两招都无效)。持有偏好属第三层。剩下的路:把出场判据做成**确定性计算**
(代码判定触发,LLM 只负责复核与说明),或换推理档位/模型再验——不是继续在 prompt 层加字段。

## 第六轮:把出场语义接成一条真链(2026-08-03/08-06)

第五轮只证明了「后端能产出 `position_action`」。用户追问「实机试验了吗」,一查:**没有**——
9999 跑的是改动前载入内存的旧代码,HTTP 端点、watcher、前端一次都没走过。补做后挖出三个真断点:

### 断点一:生产 watcher 从不传持仓语境(最重)

`seats/watcher.py::_build_payload` 里根本没有 `hold_entry`——盘中自动跑的每一拍都只问「是否进场」,
**出场问题在生产自动化里结构上从未被问过**,卖出率恒 0 与经验卡、与 `position_action` 必答字段都无关(它们都到不了)。

已接线:台账 READ-ONLY 回放取真入场价、按数字核匹配写法差异(`300308` ↔ `SZ300308`)、
台账不可读则诚实缺席绝不编价、无持仓时 payload 逐字节同旧。新增 6 项钉
(`tests/test_seats_watcher_hold_context.py`),含一项源码钉:持仓读取路径不许出现任何写形状。

### 断点二:`exit_fraction` 无下游消费——「减仓」被当成清仓执行

前端 `runBacktest` 原结构写死全进全出(`pos===1 ? shares*px : cash`),部分持仓表达不了。
已改:按 `exit_fraction` 只卖对应比例、余仓续持(入场锚不动,后续止损止盈仍按原成本判定);
净值改 `cash + shares*px`。**顺带修掉一个真 bug**:时钟出场原写 `cash = shares*exitPx`,
减仓后现金里已有前次了结的钱,这个赋值会**把它抹掉**——改成 `+=`(全平时两者等价,旧 run 逐位不变)。

### 断点三:两条取数路径映射时丢字段

`luozi-app.jsx` 的复盘行映射与今日页时间线映射都没带 `position_action` / `exit_fraction`,
后端存了、接口返了,前端拿不到。已补;三个改动过的 jsx 全部 bump `?v`(本仓已知缓存坑)。

### 一次自纠:先接到了死组件上
